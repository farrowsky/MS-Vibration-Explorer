Each case runs as a Custom design with the hand calc's members (and its infill count where the solver's own count differs). ✓ = equal to the digits the hand calc shows (or within 0.2 %); ≈ = within 1 %; ✗ = differs. **361 of 365 values match.** The other 4 are slips in the hand calcs themselves, each noted below: two typed-in Lp/Lr values that change no result, one value the study's AISC table rounds (92.6 → 93), and one capacity copied from another shape.
