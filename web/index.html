Before you start

This tool accompanies the paper Carbon-Efficient Design Strategies for Mitigating Footfall Vibration in Steel Framed Floor Systems (Farrow, Brown and Solnosky). It runs the code published with the paper so readers can see how the study's designs were produced and explore its results.

  • Not for design. Output is research data. It is not a structural design, check, specification or professional advice, and it is not a substitute for a licensed engineer's own analysis.
  • Study assumptions apply. The model covers one interior bay with the simplifications described in the paper (loads, deck tables, member selection rules, AISC Design Guide 11 walking-vibration method). Many real conditions are not considered.
  • No warranty, no liability. Provided "as is" under the MIT License. The authors, their institution and contributors accept no responsibility for any use of the results.
  • Third-party data. Steel shapes and deck values are the study's modified tables, not the official publications. Check current AISC and manufacturer data for real work.

MS Vibration Explorer is an app

This file can't run on its own. Open the tool by double-clicking MS Vibration Explorer.bat in the project folder: it starts the paper's solver and opens the app window.
